# OVH-AI-Workshop
A repo is just a fancy name for a folder. This is where all files in the project are stored.

With each change you make to a repo or the "folder" you can add a commit message to track

The best practice for the main branch is to actually think of it like the trunk of a tree. It is protected and can only be added to or altered once it.  

When we make changes to the repo best practice is open a branch to the main. or a branch to the trunk of the tree if you like.
